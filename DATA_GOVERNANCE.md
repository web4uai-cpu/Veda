# Retention

90 Days

---

Research Artifacts

365 Days

---

---

# Data Lineage

Every record must track:

* Source
* Version
* Import Date
* Citation Path

---

# Governance Principles

1. Every fact has a source.
2. Every source has lineage.
3. Every change is auditable.
4. User content is isolated.
5. Canonical content is protected.
