# ROADMAP.md

# VEDA Roadmap

Version: 1.0

Status: Active Planning

Time Horizon: 5 Years

---

# Strategic Objective

Build the world's most trusted and comprehensive AI-powered knowledge platform for Sanatan Dharma.

The roadmap prioritizes:

1. Knowledge Quality
2. Citation Reliability
3. Knowledge Graph Growth
4. Research Capability
5. User Knowledge Ownership

Before advanced AI features.

---

# Non-Negotiable Rules

1. Citation before generation.

2. Knowledge graph before advanced AI.

3. Canonical scripture before commentary.

4. Human-verifiable references.

5. No fabricated verses.

6. User uploads always separated from canonical sources.

7. Every phase must improve trust, not just features.

---

# North Star

A user can start with a single question and end with a complete understanding of the concept, its scriptural origins, philosophical interpretations, related teachings, and supporting sources without leaving the VEDA ecosystem.
