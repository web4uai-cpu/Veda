# Veda
Veda the Sanatan Philosophy, AI Sanatan Research Library,

The Knowledge Operating System for Sanatan Dharma.

VEDA is not a chatbot.

VEDA is a research platform combining:

- Vedas
- Upanishads
- Bhagavad Gita
- Puranas
- Ramayana
- Mahabharata
- Sanskrit Commentaries

Core Capabilities:

- Knowledge Graph
- Retrieval Augmented Generation
- Scripture Explorer
- Scholar Mode
- Citation Engine
- User PDF Upload
- Research Reports
- Sanskrit Analysis

Technology:

- Next.js
- FastAPI
- PostgreSQL
- Neo4j
- Qdrant
- GPT-5.5
- Claude

Architecture:

Knowledge Graph First

RAG Second

LLM Third
